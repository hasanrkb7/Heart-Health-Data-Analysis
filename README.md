# Heart Health Data Analysis

These are my weekly R exercises from the Data Visualization and Analysis course (TILP2400) at the University of Jyväskylä, April 2026. Every script works on the course health dataset, which has age, gender, smoking, cholesterol, blood pressure and other variables.

## What is inside

| Script | Theme |
|---|---|
| `Theme 1/Remon_exercises1.R` | Statistical research and data collection: loading the data, variables and types |
| `Theme 2/Remon_exercises2.R` | Reducing data into frequency and cross tables |
| `Theme 3/Remon_exercises3.R` | Data visualization: bar charts, histograms and box plots |
| `Theme 4/Remon_exercises4.R` | Summary statistics and statistical inference (confidence intervals and tests) |
| `Theme 5/Remon_exercises5.R` | Scatter plots, correlation and dependence |
| `Theme 6/Remon_exercises6.R` | Statistical modeling: linear regression |

I did not add the exam script.

## How to run

The dataset (`0.3 Datasets.txt`) belongs to the course, so it is not here.

Step 1: Put the dataset in the same folder as the script.

Step 2: Run the script in R or RStudio. The scripts use base R only.
